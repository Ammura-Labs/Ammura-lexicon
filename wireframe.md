# Wireframe: YouTube Video Scripting & AI Voiceover Assistant

## 1. Home / Upload Page
- **Top Navigation Bar**
  - Logo (top-left)
  - Links: Home | Upload | Outputs | Settings
- **Main Section**
  - Upload Card (centered)
    - Drag-and-drop area
    - File picker button
    - Text area (paste script)
  - Action Button: "Generate Outputs"

---

## 2. Processing Page
- **Progress Indicator**
  - Animated spinner or progress bar
  - Status text: "Processing your script..."
- **Pronunciation Fixer Preview**
  - Shows corrected words (WhatsApp → Whats-app, WiFi → Wi-Fye)

---

## 3. Outputs Page
- **Tabbed Layout**
  - Tabs: Narrative | Subtitles | Blog | Notes
- **Content Area**
  - Display generated text
  - Download buttons for each file
- **Optional Audio**
  - Play button for generated voiceover (`voiceover.mp3`)

---

## 4. Settings Page
- **Pronunciation Dictionary**
  - Add/Edit custom word corrections
- **Theme Options**
  - Dark/Light mode toggle
  - Accent color selector
- **Preferences**
  - Default output formats
  - Subtitle timing options (future)
