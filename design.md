# Design: YouTube Video Scripting & AI Voiceover Assistant

## 1. Theme & Concept
- **Theme**: Futuristic minimalism with a professional creator vibe.
- **Mood**: Clean, modern, slightly techy — feels like a creative studio tool.
- **Primary Goal**: Keep the interface simple, intuitive, and visually appealing for creators.

---

## 2. Color Palette
| Element            | Color Code | Purpose |
|--------------------|------------|---------|
| **Background**     | `#0b0c1a` (Deep Navy) | Calm, immersive base |
| **Primary Accent** | `#5b6eff` (Electric Blue) | Buttons, highlights |
| **Secondary Accent** | `#9b8cff` (Violet) | Hover effects, gradients |
| **Text Primary**   | `#e0e0e0` (Light Gray) | Readable contrast |
| **Text Secondary** | `#9aa0b8` (Muted Gray) | Subtle secondary text |
| **Error/Alert**    | `#ff4d4d` (Bright Red) | Error messages |
| **Success**        | `#4caf50` (Green) | Success confirmations |

---

## 3. Typography
- **Primary Font**: `Inter` (modern, clean, highly readable)
- **Secondary Font**: `Roboto Mono` (for code snippets or technical text)
- **Headings**: Bold, uppercase, slightly larger spacing
- **Body Text**: Regular weight, high readability
- **Notes/Secondary Info**: Smaller size, muted color

---

## 4. Layout & Components
- **Navigation Bar**: Top bar with logo and navigation links (Home, Upload, Outputs, Settings).
- **Upload Section**: Centered card with drag‑and‑drop or file picker.
- **Processing Status**: Animated progress bar or spinner with clear text feedback.
- **Output Section**:
  - Tabs for Narrative, Subtitles, Blog, Notes.
  - Download buttons for each file.
- **Error/Success Messages**: Toast notifications at bottom‑right.

---

## 5. UI Elements
- **Buttons**:
  - Rounded corners, glowing hover effect.
  - Primary (blue), Secondary (violet), Danger (red).
- **Cards**:
  - Dark background with subtle shadow.
  - Glow accent on hover.
- **Text Areas**:
  - Monospaced font for script editing.
  - Highlighted keywords for pronunciation fixes.

---

## 6. Icons & Visuals
- **Icons**: Minimal line icons (Feather Icons or Material Icons).
- **Visual Effects**:
  - Subtle particle background (optional).
  - Gradient glow transitions on hover.

---

## 7. Accessibility
- High contrast between text and background.
- Large clickable areas for buttons.
- Keyboard navigation support.
- Screen reader compatibility.

---

## 8. Future Enhancements
- Theme switcher (Dark/Light mode).
- Customizable accent colors.
- Animated avatars or assistant mascot (optional).
